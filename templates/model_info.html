How It Works

The ML model uses a K-Neighbors Classifier (KNN) trained on both fake and legitimate job postings. This algorithm classifies new job posts by finding the k (5) nearest training samples and using their labels to make predictions.

Key Features Analyzed:

  • Job description language and terminology
  • Salary information patterns
  • Company name legitimacy
  • Job title relevance
  • Common scam keywords (money upfront, easy money, etc.)
  • Text sentiment and urgency indicators

📚 Technical Details

File Structure: The ML model is implemented in a separate module (ml_model.py) for better code organization and maintainability. The FakeJobPostDetector class encapsulates all model logic including training, prediction, and data processing.

Dependencies: scikit-learn, numpy
