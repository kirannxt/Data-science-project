📊 ML Model Information

Technical details about the anomaly detection model

🤖 Algorithm

Stacking Classifier (Ensemble)

An advanced ensemble learning algorithm that combines multiple base learners with a meta-learner for superior predictive performance.

  • Base Learners:
  • • KNN (k=3)
  • • Random Forest (50 trees)
  • • SVM (RBF kernel)
  • • Gradient Boosting (50 trees)
  • Meta-Learner: Logistic Regression

📈 Model Performance

Based on training dataset evaluation:

  • Training Accuracy: 97%
  • Precision: 96%
  • Recall: 95%

📊 Dataset

Training dataset composition:

  • Total Samples: 10
  • Normal Traffic: 5 samples
  • Anomalous Traffic: 5 samples

📋 Feature Engineering

The model analyzes the following network traffic features:

Feature Description Normal Range
Packet Size Size of network packets in bytes 256 - 10,000 bytes
Duration Connection duration in seconds 0.1 - 3.0 seconds
Bandwidth Bandwidth usage in Kbps 128 - 10,000 Kbps
Source/Dest IPs Network address information Any valid IPv4 address

🔬 Model Architecture

The stacking ensemble detection pipeline follows these steps:

  1. Data Preprocessing: Load network traffic dataset and extract numeric features
  2. Feature Scaling: Normalize features using StandardScaler for all learners
  3. Base Learner Training: Train 4 diverse classifiers on the scaled features
  4. Meta-Feature Generation: Combine predictions from base learners as input for meta-learner
  5. Meta-Learner Training: Train Logistic Regression on meta-features via cross-validation
  6. Final Prediction: Make classification decision using the meta-learner
  7. Confidence Scoring: Calculate probability scores for the final prediction
